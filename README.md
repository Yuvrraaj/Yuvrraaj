### Self-Pruning Neural Network &nbsp;`ML Research`
Weight removal as an intrinsic training objective - not a post-training step. Learnable gate scalars with L1 regularisation drive sparsity during training. At λ = 5e-5: **92.95% weights pruned, <0.44% accuracy drop** from dense baseline. Gate histograms confirm bimodal distribution - surgical removal, not random destruction.  
`PyTorch` `Custom PrunableLinear layers` `CIFAR-10` `BatchNorm` `λ warm-up scheduling`  
→ [github.com/Yuvrraaj/Self-Pruning-Neural-Network](https://github.com/Yuvrraaj/Self-Pruning-Neural-Network)
